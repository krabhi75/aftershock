---
id: INC-1177
title: A label was printed for a parcel that was on no manifest
fault_class: partial_commit
fixed_symbol: harborline.paperwork.print_outbound_label
---

The manifest service returned an error after the label write had already landed. Dock staff applied a label for parcel HBL-44021, and that parcel was on no truck.

`print_outbound_label` now performs the label write and the manifest write inside `unit_of_work`, which restores both lists if the second write raises. Booking a return leg and rerouting mid-route still call two writes back to back, with no unit of work and no compensating rollback.
