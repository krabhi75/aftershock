# Bob task screenshots

The September 2026 IBM Bob 2.0 guide requires one PNG per relevant Bob task: the task session consumption summary.

Capture them from the hackathon Bob account after you run `DEMO.md`.

Suggested names:

- `aftershock_task01_read_incident_summary.png`
- `aftershock_task02_parallel_siblings_summary.png`

Two tasks are enough. Do not open a third Bob task unless the coin meter is still low and Task 2 failed.

In Bob: Tasks → open the task → click the task header → screenshot the consumption summary.

Do not put API keys, IBMid passwords, or cloud credentials in this folder.
